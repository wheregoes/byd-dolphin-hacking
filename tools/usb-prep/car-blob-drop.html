Drop app to your BYD

This page puts the APK straight into Downloads on the car (bypasses the blocked downloader). No ADB needed for the file itself.
After the file lands (you will see a success message):
1
Open a file manager on the car (install one first via the USB "Third Party Apps" method if you don't have one).
2
Go to Downloads (or /sdcard/Download).
3
Tap the APK → choose Package Installer (or microG / GPack if shown) → tap Install.
4
Allow "install from this source" if it asks the first time.
Works because the browser's normal download path is killed by BYD, but fetch() + Blob + <a download> writes the bytes directly and survives.

For the absolute first app on a completely stock car use the USB magic folder method (see the prep tool in this repo). After that this + a file manager is all you need.
